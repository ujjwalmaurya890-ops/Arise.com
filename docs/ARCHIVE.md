# Archived audits

The dated reports in this directory (`AUDIT-2026-11-04.md`,
`ENGINEERING-OVERHAUL-2026-10-30.md`, `QA-AUDIT-2026-10-28.md`,
`LOADING-AUDIT-2026-10-29.md`, `REPOSITORY-AUDIT.md`, …) are point-in-time
snapshots. They are kept for history; do not treat their "remaining work"
lists as current. Current state is described by `README.md`,
`ARCHITECTURE.md`, and `docs/SECURE-SYNC.md`. New audits should supersede
(rather than duplicate) these files.
